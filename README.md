# 소미의 어드벤처 타임

회색 안개에 색을 빼앗긴 꿈나라에서 소미가 동물 친구들과 함께 일곱 가지 꿈빛을 되찾고,
마지막 달빛 정원에서 혼자 울고 있던 아이를 만나러 가는 3D 액션 어드벤처입니다.
그래픽, 캐릭터, 애니메이션, 음악, 효과음은 모두 코드로 직접 만들었습니다(외부 에셋 없음).

## 바로 하기

| 방법 | 설명 |
| --- | --- |
| 웹 (GitHub Pages) | https://yongillion.github.io/somis-adventure-time/ — 휴대폰·태블릿·PC 어디서나 |
| `index.html` 더블클릭 | 인터넷 없이도 PC 브라우저에서 바로 실행돼요 (`dist/index.html`도 같아요). |
| 원본(모듈) 실행 | 이 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속 |
| 휴대폰·태블릿 | 같은 와이파이에서 PC 주소(예: `http://192.168.0.10:8000`)로 접속하거나 공유 링크로 열어요. |

최신 크롬, 사파리, 엣지(WebGL2 지원)에서 동작합니다. 휴대폰은 가로 화면으로 해 주세요.

## 조작법

| 동작 | 터치 | 키보드 | 게임패드 |
| --- | --- | --- | --- |
| 이동 | 왼쪽 화면 어디든 끌기(가상 조이스틱) | WASD / 방향키 | 왼쪽 스틱, 십자키 |
| 점프 · 공중에서 길게 누르면 둥실 | 점프 버튼 | Space / K / Z | A |
| 공격(빨아들이기 → 뱉기) | 별 버튼 | J / X | X 또는 B |
| 동물 친구 특기 | 반짝이 버튼 | L / C / Shift | Y 또는 RT |
| 동물 친구 바꾸기 | 오른쪽 위 동물 버튼 | 1 / R / Tab | LB |
| 펫 상자 | 오른쪽 위 펫 버튼 | 2 / F | RB |
| 카메라 돌리기 | 오른쪽 화면 끌기 | Q / E | 오른쪽 스틱 |
| 일시정지 | 일시정지 버튼 | Esc / P | Start |

휴대폰에서 처음 화면의 TOUCH를 누르면 전체 화면으로 바뀌어요. 놀다가 뒤로 가기로 전체 화면이
풀리면 게임이 저절로 멈추고, 다시 화면을 누르면 이어서 할 수 있어요.

## 게임 내용

- **스테이지 8개** (각 약 10분): 꽃구름 들판 · 노을 과일 협곡 · 해바라기 꿀벌 언덕 · 반딧불 정글 ·
  수정 바다 · 오로라 눈꽃 산 · 장난감 시계탑 · 달빛 꿈의 정원. 스테이지마다 보스, 숨은 뭉실이 5마리,
  꿈 등불(체크포인트), 비밀 장소가 있어요.
- **동물 친구 30종**: 숨겨진 특별 쿠키를 먹으면 함께하게 되고, 언제든 바꿔서 각자의 특기
  (드래곤 비행, 캥거루 슈퍼 점프, 돌고래 방울 방패, 돼지 보물찾기 등)로 길을 열어요.
- **날개 달린 펫 15종**: 꿀벌, 나비, 참새, 갈매기, 앵무새, 부엉이 등을 이벤트로 만나 펫 상자에 모으고,
  한 마리를 불러 함께 다녀요. 함께할수록 레벨이 올라 능력이 강해져요.
- **난이도**: 보통 / 어렵게 / 매우 어렵게 (설정에서 언제든지 변경)
- 오프닝, 스테이지 사이 추억 장면, 엔딩과 크레디트가 있어요. 진행 상황은 브라우저에 자동 저장돼요.

## 폴더 구조

```
index.html            원본 진입점 (ES 모듈)
css/style.css         화면 UI 스타일
js/main.js            부팅
js/engine/            자체 WebGL2 엔진 (렌더러·툰 셰이더·지오메트리·입력·오디오 합성·파티클)
js/game/              게임 (플레이어, 카메라, 물리, 모드, UI, 시스템)
  levels/stage1~8.js  스테이지 구성
  bosses/             보스 8종
  models/             동물·펫·적·NPC·소품 절차적 모델
  story/              컷신 연출, 오프닝·추억·엔딩
  data/               스테이지·동물·펫 데이터
dist/                 배포판 (npm run build 로 생성)
docs/                 설계 문서
tools/                테스트·검증 도구 (자동 플레이 봇, 화면 투어, 성능 측정)
```

## 개발

```
npm install              # esbuild, playwright (개발 도구용)
npm run build            # js/ 모듈을 dist/game.js 하나로 묶기
python -m http.server 8765
```

GitHub Pages는 `main` 브랜치의 루트를 그대로 서비스해요 (Settings → Pages → Deploy from a branch → `main` / `(root)`).
첫 화면 `index.html`은 플레이어에게는 묶음 빌드(`dist/game.js`)를, localhost나 `?dev=1`에서는 `js/` 모듈을 불러와요.
그래서 코드를 고친 뒤에는 `npm run build`로 dist를 다시 만들어 함께 push해 주세요.

검증 도구는 `http://127.0.0.1:8765` 에 띄운 상태에서 실행해요.

| 도구 | 하는 일 |
| --- | --- |
| `node tools/botrun.mjs "http://127.0.0.1:8765/?stage=3&flags=seen:stage3intro" out tools/routes/stage3.json 40000 6000 1` | 웨이포인트 봇이 스테이지를 끝까지 플레이 (무적 모드) |
| `node tools/tour.mjs 3 out` | 꿈 등불마다 플레이어 카메라 화면 캡처 |
| `node tools/checkspawns.mjs` | 모든 스테이지의 부활 지점·배치 검사 |
| `node tools/perf.mjs` | 스테이지별 업데이트 시간·드로우콜 측정 |

개발용 주소 옵션: `?stage=5` (스테이지 바로 시작), `?seq=opening`·`?seq=memory3`·`?seq=ending`·`?seq=credits` (연출만 보기)
